# FS25-trackArray-Importer
I, together with Claude have created the trackArray.dds importer for FS25. (Should work with FS22, haven't tested)

This is tested on FS25 EC250DL crawler. Issues and problems for Blender versions lower then 5.2 LTS is not supported. 
If you report a bug, please include the log, Blender version, version of the trackArray Importer and any other information that may be useful.

Please bear in mind that is my first Repository so it is not 100% professional.
